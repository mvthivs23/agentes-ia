## Antes de ejecutar el código

1. Crea el entorno virtual y actívalo (capítulo 02).
2. Guarda las claves en un archivo `.env` y agrégalo a `.gitignore`.
3. Verifica las claves con `verificar_claves.py`.

Nunca subas `.env` ni `.venv/` a Git.
